Suporte guiado pelo Codex

Quando algo parecer errado, digite solucao de problemas no Codex

A solucao de problemas do NoDrift acontece dentro do workspace do usuario. A pagina publica mostra o modelo de suporte; os prompts diagnosticos e checklists exatos sao exclusivos do comprador.

O gatilho simples

Se algo der errado enquanto voce ja esta trabalhando no seu workspace NoDrift, envie isto ao Codex:

troubleshooting

O guia do comprador fornece a formulacao diagnostica exata. O Codex deve pausar o trabalho normal, delimitar o problema, inspecionar apenas o necessario, explicar o que encontrou e pedir aprovacao antes de alterar, mover, excluir, restaurar, publicar, fazer push, fazer upload ou editar qualquer coisa.

Papel do site

Esta pagina explica onde a solucao de problemas acontece. O site nao inspeciona arquivos locais e nao e um bot de suporte ao vivo.

Papel do Codex

O agente Codex trabalha dentro do workspace NoDrift do usuario, onde materiais exclusivos do comprador podem orientar diagnostico seguro quando verificacoes forem necessarias.

Triagem rapida

Problemas comuns e areas seguras de solucao de problemas

Comece pelo sintoma. O Codex deve delimitar o escopo antes de tocar em arquivos. Checklists exatos sao exclusivos do comprador.

Configuracao

NoDrift pode estar na pasta errada

Use o guia de solucao de problemas do comprador para confirmar o workspace ativo e o local pretendido do projeto.

Checklist diagnostico privado
Inicializacao

A inicializacao nao comecou corretamente

Use o guia de solucao de problemas do comprador para confirmar que a primeira configuracao ocorreu na ordem pretendida.

Regras

O Codex nao esta seguindo as regras do NoDrift

Use o guia de solucao de problemas do comprador quando o Codex exagerar afirmacoes, pular um limite ou parecer estar usando o contexto errado. As etapas exatas de revisao sao privadas.

Verificacao

Uma afirmacao parece completa demais

Use o guia de solucao de problemas do comprador quando uma afirmacao parecer mais ampla do que a evidencia. O metodo exato de cobertura e informacao interna privada.

Recuperacao

O trabalho aconteceu no chat ou na unidade errada

Use o guia de solucao de problemas do comprador antes de copiar, mover ou excluir qualquer coisa. O Codex deve separar locais confirmados de locais incertos antes da recuperacao.

Continuidade

Confusao de continuidade ou chat compactado

Use o guia de solucao de problemas do comprador quando decisoes anteriores parecerem ausentes ou fora de ordem. O procedimento exato de continuidade e informacao interna privada.

Privacidade

Arquivos publicos e privados podem estar misturados

Use o guia de solucao de problemas do comprador antes de publicar, fazer upload, fazer push, compartilhar ou enviar qualquer coisa. Registros privados do workspace nao sao material de site publico.

Publicacao

O estado do GitHub ou do site esta incerto

Use o guia de solucao de problemas do comprador antes de publicar no GitHub ou no site. Previa local, estado do repositorio e paginas publicas ativas sao estados separados.

Pontos de parada

O que o Codex nao deve fazer sem aprovacao

A solucao de problemas pode inspecionar dentro do escopo. Mudancas consequentes ainda precisam de aprovacao.

Seguranca de arquivos

Nao exclua nem sobrescreva primeiro

Arquivos parecidos, pastas antigas, copias na unidade C, copias na unidade G e versoes do GitHub precisam ser inventariados antes que qualquer coisa seja excluida, substituida ou movida.

Acoes externas

Nada de publicar, fazer push, upload ou enviar por implicacao

Acesso nao e aprovacao. Previa local nao e o site publico. Estado do repositorio GitHub nao e a mesma coisa que publicacao no GitHub Pages.

Registros privados

Mantenha a memoria privada

Registros privados de continuidade, registros de correcao, registros de fonte e notas de trabalho nao sao material de site publico, a menos que o usuario autorize explicitamente uso externo.

Exclusivo do comprador

Prompts diagnosticos

A biblioteca exata de prompts diagnosticos e informacao interna privada incluida no workspace do comprador.

Protegido

Biblioteca interna privada de prompts

Frases diagnosticas exclusivas do comprador

O site publico mostra que a solucao de problemas guiada existe; ele nao publica o conjunto completo de prompts.

A solucao de problemas deve terminar com uma proxima diretiva clara. Se o proximo passo alterar, mover, excluir, restaurar, publicar, fazer push, fazer upload ou editar qualquer coisa, o Codex deve pedir aprovacao explicita.
