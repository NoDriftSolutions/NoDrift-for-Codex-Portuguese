Primeiros passos

Primeiros passos explica a inicialização em resumo: coloque o pacote de governança na pasta do projeto, use begin, deixe o Orquestrador de IA ler e ativar a governança, depois descreva o projeto e comece o trabalho.

1. Coloque o pacote de governança na pasta do projeto

NoDrift começa dentro da pasta real do projeto. O pacote de governança fica ali para que o app ativo de projeto com IA trabalhe com o mesmo projeto, registros, limites e controles desde o primeiro momento da configuração.

2. Abra o projeto no Orquestrador de IA e digite begin

O gatilho de inicialização é simples. Abra o projeto como o espaço de trabalho ativo do Orquestrador de IA e use begin para iniciar a rotina de inicialização do NoDrift.

3. O Orquestrador de IA lê os arquivos de governança

O Orquestrador de IA lê o arquivo raiz AGENTS.md e o pacote de governança instalado, depois carrega os limites do projeto, regras de inicialização, lógica de aprovação, disciplina de fontes e registros ativos necessários para trabalho governado.

4. O Orquestrador de IA configura a governança e então pergunta sobre o projeto

Quando a inicialização termina, o Orquestrador de IA pede que o usuário descreva o projeto. O trabalho então começa sob governança ativa, com controles de fonte, aprovação, continuidade, evidência e correção já em vigor.

5. Deepen Later

A primeira passagem serve para ativar rapidamente o espaço de trabalho. Personalização mais profunda, rotinas de verificação mais fortes e opções estendidas de governança podem ser adicionadas depois sem bloquear a inicialização.
