Demonstrator

O ponto de partida gratuito serve para mostrar o controle comportamental central do NoDrift: respostas com fonte, permissão limitada e uma parada visível antes de ação pública ou externa.

Upgrade para Basic

Basic é o primeiro caminho de pacote de compra depois do Demonstrator. Ele fica posicionado como o próximo passo para um usuário individual de Claude Code que quer configuração de projeto, continuidade, aprovação e verificação mais completas.

Extended

Extended é o nível individual superior para trabalho maior ou de maior risco, com controles mais fortes de passagem de contexto, evidência, prontidão e segurança de alegações.

Teams / Enterprise

Teams / Enterprise é a direção organizacional para trabalho compartilhado, aprovações por papel, escalonamento, supervisão e decisões mais seguras de lançamento ou diante de clientes.

Limite de status

Esta página fornece o destino público para upgrade ao Basic. Preço, checkout, pagamento, download, entrega, suporte, prontidão para compradores e linguagem final de disponibilidade continuam limitados até aprovação separada.

Do gratuito à primeira compra

Demonstrator apresenta o padrão de comportamento NoDrift. Basic é o caminho público de upgrade quando o usuário está pronto para sair de um começo gratuito controlado e entrar na primeira faixa paga de pacote.

Continuidade

As mesmas ideias NoDrift se aplicam, mas o pacote precisa combinar com a forma como Claude Code mantém o contexto do projeto.

Limite por nível

A estrutura de quatro níveis esclarece o caminho sem afirmar que todos os níveis estão prontos hoje.
